# Hospital Emergency Room Analysis Dashboard Using MS Excel
## 1. Project Objective
The objective of this project is to analyze Hospital Emergency Room (ER) data and create an interactive Excel dashboard that helps understand patient volume, admission status, waiting time, satisfaction, timeliness, demographics, and department referrals.
The dashboard is designed to convert raw hospital data into meaningful information that can help identify patterns and support better decision-making.

## 3. Business Questions / KPIs
The dashboard answers the following key questions:

KPI 1 — Total Patients
-How many patients visited the emergency room?

-What is the daily patient volume trend?

KPI 2 — Average Wait Time
-What is the average time patients waited to see a medical professional?

-Are there days with unusually high waiting times?

KPI 3 — Patient Satisfaction
-What is the average patient satisfaction score?

-How does satisfaction change over time?

KPI 4 — Patient Admission Status
-How many patients were Admitted?

-How many were Not Admitted?

KPI 5 — Timeliness
-What percentage of patients were seen within 30 minutes?

-What percentage experienced a delay?

KPI 6 — Gender Analysis
-What is the distribution of patients by gender?

KPI 7 — Age Distribution
-Which age groups have the highest number of patients?

KPI 8 — Department Referrals
-Which departments receive the highest number of patient referrals?

## 4. Project Process
The project was completed through an end-to-end data analytics workflow:
Step 1 — Business Requirement Gathering

Identified the key business questions and KPIs required for the ER analysis.

Step 2 — Understanding the Data

Reviewed the available patient fields and understood the meaning of each column.

Step 3 — Data Import

Imported the hospital ER data into Excel using Power Query.

Step 4 — Data Cleaning

Cleaned and checked the dataset for data quality issues using Power Query.

Step 5 — Calendar Table

Created a calendar table to support date-based analysis.

Step 6 — Data Modeling

Created relationships and organized the data using Power Pivot.

Step 7 — Calculated Columns

Created required calculated fields such as Age Group and Patient Attendance Status using DAX.

Step 8 — Pivot Tables

Created Pivot Tables to summarize patient data and calculate KPIs.

Step 9 — Visualization

Created charts and formatted them to clearly communicate the results.

Step 10 — Dashboard Development

Combined KPIs, charts, filters, and interactive elements into the final Excel dashboard.

Step 11 — Insights Generation

Analyzed the dashboard results and identified important patterns in the ER data.

## 6. Project Insights
Based on the current January 2024 dashboard view:
513 patients visited the emergency room.
269 patients (52%) were admitted.
244 patients (48%) were not admitted.
62% of patients experienced a delay, while 38% were seen on time.
The average wait time was 36.32 minutes.
The average patient satisfaction score was 4.96/5.
53% of patients were male and 47% were female.
The 0–9 age group had the highest number of patients with 76 patients.
Among referral departments, General Practice had the highest number of referrals at 103, followed by Orthopedics with 65.
299 patients had no department referral.

## 7. Final Conclusion
This project provided hands-on experience in building an end-to-end Data Analytics project using Excel.By using Power Query, Power Pivot, DAX, Pivot Tables, charts, KPIs, and interactive filters, raw hospital ER data was transformed into an easy-to-understand dashboard. The project helped demonstrate how Excel can be used not only for data manipulation but also for data analysis, visualization, and extracting meaningful business insights.
